  # qrception

  basic qrcode generator without any dependency that fits in less than 3KB.

</div>

> [!NOTE]
> The generator only supports qr code versions 1-4 (78 bytes max) in bytes mode with L error correction.

## Demo

copy the content of [this](https://github.com/Paylicier/qrception/dist/uri.txt) file into your url bar

### Build

1. Clone the repository:
   ```bash
   git clone https://github.com/Paylicier/qrception.git
   cd qrception
   ```

2. Install dependencies:
   ```bash
   bun install
   ```

3. Build:
   ```bash
   bun build.mjs
   ```
4. Generated files will be available in dist/
